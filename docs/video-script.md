## לפני שמתחילים — הכנות

פתח מראש את הלשוניות האלה **בסדר הזה**, כדי שלא תחפש באמצע ההקלטה:

2. n8n — מסך Overview → Workflows
3. Airtable — טבלת `Invoices`
4. טלגרם Web — בוט הלקוחות
5. טלגרם Web — בוט המנהל

7. GitHub — `github.com/nazulay4-wq/erp-ai-n8n`

**נקה את המסך:** סגור התראות, הסתר סימניות מיותרות (`Ctrl+Shift+B`), הפעל מצב מסך מלא (`F11`) בכל לשונית. הגדל את זום הדפדפן ל-110% כדי שהטקסט יהיה קריא בווידאו.

**כלי הקלטה:** Windows Game Bar (`Win+G` → כפתור ההקלטה). לעריכה וכתוביות: Clipchamp (מגיע עם Windows).

## פרק 3 — המערכת בפעולה · 0:45–2:15

זה הלב. מראים מחזור חיים שלם של ליד, ואז את סוכני ה-AI.

### 3א · ליד נכנס (0:45–1:05)

**מה רואים:** טופס הליד → Airtable.

**כתובית:**
```

```
**פעולות:** מלא טופס עם שם בדוי, שלח. עבור ל-Airtable → `Leads` → הצבע על השורה החדשה.

**כתובית:**
```

```

### 3ב · מייל קר אוטומטי (1:05–1:25)

**מה רואים:** Gmail, ההודעה היוצאת שנשלחה ע"י WF4a.

**כתובית:**
```
סוכן מכירות מנסח מייל קר בעברית ושולח ללקוח
```
פתח את המייל, גלול בגוף ההודעה.

**כתובית:**
```

```
חזור ל-Airtable והצבע על ליד בסטטוס `Replied`.

### 3ג · בוט שירות לקוחות — RAG (1:25–1:50)

**מה רואים:** טלגרם, בוט הלקוחות.

**כתובית:**

**כתובית:**

### 3ד · הפקת חשבונית (1:50–2:15)

**מה רואים:** Airtable → מסמך Google.

**כתובית:**
```

```

**כתובית:**

**מה רואים:** החשבונית המעוצבת נפתחת. השהה עליה שתי שניות.

**כתובית:**
